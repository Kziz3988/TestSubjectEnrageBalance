# Test Subject Enrage Balance Mod

# 实验体激怒优化Mod

### This mod requires [BaseLib](https://github.com/Alchyr/BaseLib-StS2) to run properly

### 此Mod需要[BaseLib](https://github.com/Alchyr/BaseLib-StS2)才能正常运行

This mod has modified the Enrage power in phase 1 of the Test Subject.

这个Mod对实验体一阶段的“激怒”效果进行了修改。

The effect has been modified to: Whenever a player plays a skill card, the Test Subject applies an Enraged debuff to the player.

该效果被修改为：每当玩家打出一张技能牌，实验体对该玩家施加相应层数的“触怒”状态。

The player receives additional damage equal to the counter of Enraged from the Test Subject.

实验体对玩家额外造成“触怒”层数的伤害。

This additional damage has the same priority as strength, which means it settles before weakness and vulnerability.

该额外伤害与力量同级，这意味着其在虚弱和易伤之前计算。

This also means that the settlement effect of the Enrage power in single player mode is the same as that of the vanilla game.

这也意味着“激怒”效果在单人模式下与原版游戏相同。

Enrage and Enraged powers will be cleared after phase 1 of the Test Subject is defeated.

在实验体一阶段被击败后，“激怒”和“触怒”将被清除。

The mod did not modify phase 2 and 3 of the Test Subject.

Mod没有对实验体的二阶段和三阶段进行修改。
